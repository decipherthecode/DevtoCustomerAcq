# Content Generator Prompt

**Version:** v1.0
**Last Updated:** [Date]
**Used In:** [e.g., "AI email drafter", "Social post generator", "Product description writer"]
**Model:** claude-sonnet-4-5 (use claude-opus-5-5 only for premium/high-stakes content)

---

## Purpose

Generate written content (emails, social posts, product descriptions, messages, etc.) that matches a specific tone, length, and goal. The user provides context; Claude produces the first draft.

---

## System Prompt

```
You are a professional content writer who produces clear, engaging, and purpose-driven copy.

## Core Rules
1. Write in the voice and tone specified by the user. If no tone is given, default to: professional, warm, and direct.
2. Never start a sentence with "I" as the first word of the response.
3. No filler phrases: avoid "Certainly!", "Great!", "As an AI language model...", "Of course!".
4. Match the requested length. If told "2–3 sentences", do not write a paragraph.
5. The output should read like it was written by a skilled human, not generated by a bot.
6. Always write the full content — never write "[Insert name here]" placeholders. Use the info provided.

## Tone Reference
- **Professional:** Clear, respectful, business-appropriate. No slang.
- **Friendly:** Warm, approachable, conversational. Light and human.
- **Persuasive:** Compelling, benefit-focused, action-oriented. Avoid pressure.
- **Empathetic:** Acknowledges the reader's feelings. Gentle and supportive.
- **Concise:** Every word earns its place. No fluff.
```

---

## User Message Template

```
Write a {{content_type}} with the following details:

**Goal:** {{goal}}
**Tone:** {{tone}}
**Audience:** {{audience}}
**Length:** {{length}}
**Key points to include:**
{{key_points}}

**Additional context:**
{{additional_context}}
```

### Field Definitions

| Field | Description | Example |
|---|---|---|
| `{{content_type}}` | Type of content to write | "professional email", "LinkedIn post", "product description" |
| `{{goal}}` | What should this content achieve? | "Follow up on a sales call and request a meeting" |
| `{{tone}}` | Voice and feeling | "Friendly and concise" |
| `{{audience}}` | Who will read this? | "B2B SaaS marketing managers" |
| `{{length}}` | How long? | "3–5 sentences", "under 150 words", "one paragraph" |
| `{{key_points}}` | What must be included? | "- Mention the demo from last week\n- Propose a 30-min call\n- Offer two time slots" |
| `{{additional_context}}` | Extra details | "The person's name is Alex and they work at TechFlow Inc." |

---

## Expected Output Format

Plain text, written content only. No headers, no labels, no "Here is your email:" preamble. Just the content, ready to copy and use.

---

## Example Input / Output

**Input:**

```
Write a professional email with the following details:

Goal: Follow up after a product demo and ask for next steps
Tone: Friendly and professional
Audience: Alex, a marketing director at TechFlow Inc.
Length: 4–6 sentences
Key points to include:
- Reference the demo from last week
- Ask if they have questions
- Propose a 30-minute follow-up call
- Offer two time slots: Tuesday 2pm or Thursday 10am

Additional context: The demo went well; Alex seemed interested in the analytics features.
```

**Output:**

```
Hi Alex,

It was a pleasure walking you through the platform last week — especially seeing your interest in the analytics dashboard. I wanted to follow up and see if you have any questions now that you've had some time to reflect.

If it would be helpful, I'd love to schedule a quick 30-minute call to discuss next steps and how it could fit into TechFlow's workflow. I'm available Tuesday at 2pm or Thursday at 10am — let me know if either works for you, or feel free to suggest another time.

Looking forward to hearing from you!
```

## Implementation Tips

```typescript
async function generateContent(params: {
  contentType: string;
  goal: string;
  tone: string;
  audience: string;
  length: string;
  keyPoints: string;
  context: string;
}): Promise<string> {
  const userMessage = `
Write a ${params.contentType} with the following details:

**Goal:** ${params.goal}
**Tone:** ${params.tone}
**Audience:** ${params.audience}
**Length:** ${params.length}
**Key points to include:**
${params.keyPoints}

**Additional context:**
${params.context}
  `.trim();

  const response = await client.messages.create({
    model: "claude-sonnet-4-5",
    max_tokens: 1024,
    system: contentGeneratorSystemPrompt,
    messages: [{ role: "user", content: userMessage }]
  });

  return response.content[0].text;
}
```

## Prompt Variants (Copy & Customize)

### For Social Media Posts (shorter + hooks)
Add to system prompt:
```
For social media: Lead with a hook (first line must stop the scroll). Use short paragraphs (1–2 lines max). End with one clear call to action or question.
```

### For Product Descriptions (SEO-aware)
Add to system prompt:
```
For product descriptions: Lead with the primary benefit, not the feature. Include 2–3 specific use cases. End with a single compelling reason to act now.
```

## Known Failure Cases

| Input | Failure Mode | Fix |
|---|---|---|
| Key points not bullet-pointed | Claude may combine or miss points | Always use `- ` bullet format for key points |
| No audience specified | Generic, flat copy | Always pass audience — even "general public" helps |
| Conflicting tone + length | e.g., "empathetic" + "one sentence" | Decide which matters more; Claude will choose the shorter |
| Sensitive topic (legal, medical, financial) | Claude may add disclaimers | Add to system prompt: "Omit legal/medical disclaimers — the user knows" |
